# Contributing to 2026 Builder Stack

Thank you for your interest in contributing! This directory is maintained by the community to keep track of the most useful AI tools, frameworks, and agents.

## How to Add a Tool

1. **Fork the repository** and create your branch from `main`.
2. **Find the right category** in the `README.md`. If your tool doesn't fit existing categories, consider adding a new one or placing it in "Hidden Gems" / "Emerging Projects".
3. **Format your entry** using the following Markdown table row structure:
   
   ```markdown
   | Tool Name | Rating | Type | Open Source | Description | GitHub | Website |
   ```

4. **Ratings Guide**:
   - ⭐⭐⭐⭐⭐ Essential, best in class, widely adopted.
   - ⭐⭐⭐⭐☆ Excellent, recommended for most projects.
   - ⭐⭐⭐☆☆ Good but niche or newer.

5. **Commit your changes** with a clear message (e.g., `Add MyNewAgent to AI Agents`).
6. **Submit a Pull Request**.

## Guidelines

- **Quality over Quantity**: Only add tools that are genuinely useful or technically impressive.
- **Accuracy**: Ensure GitHub links and websites are correct and official.
- **Descriptions**: Keep descriptions concise (1-2 sentences max) and focused on what the tool actually does.

Thank you for helping build the ultimate AI engineering resource!
